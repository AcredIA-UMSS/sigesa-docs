# Aplicaciones SIGESA (repositorios separados)

El código de las aplicaciones **no** forma parte del historial de `sigesa-docs`. Cada carpeta es su propio repositorio Git:

| Carpeta | Repositorio |
|---------|-------------|
| `sigesa-front/` | Frontend Next.js (MVP CC/TD) |
| `sigesa-backend/` | Backend microservicios (Evidence, Audit, Gateway) |

Clona o trabaja en cada repo de forma independiente. La documentación canónica y las skills viven en la raíz de este monorepo (`docs/`, `.cursor/skills/`).
