## Resumen

Requisitos no funcionales de SIGESA organizados por **ISO/IEC 25010** (eficiencia, compatibilidad, usabilidad, fiabilidad, seguridad, mantenibilidad, portabilidad).

| Esquema ID | Ejemplos |
|------------|----------|
| **NFR-001 … 013** | Buscador ≤ 3 s, PDF ≤ 5 min, notif. ≤ 15 min, uptime ≥ 99 %, TLS, auditoría 100 % |
| **NFR-ED-01, SEG-01, FIA-01, …** | Catálogo arquitectónico SRE (latencia, pentest, RTO/RPO, CI/CD) |
